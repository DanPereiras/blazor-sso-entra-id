# Blazor SSO Authentication with Entra ID

## Overview

This project demonstrates the integration of a Blazor application with Microsoft Entra ID using Single Sign-On (SSO).

The goal is to explore how modern identity providers can centralize authentication and improve security architecture.

## Security Problem

Traditional applications often manage authentication locally, which increases risk and complexity.

Modern architectures prefer delegating authentication to trusted identity providers.

## Solution

This project integrates a Blazor application with Microsoft Entra ID to implement SSO authentication.

Authentication is handled by the identity provider instead of the application itself.

## Technologies Used

- Blazor
- Microsoft Entra ID
- OAuth / OpenID Connect

## Security Concepts Demonstrated

- Identity-based security
- Single Sign-On authentication
- Modern identity provider integration

## Lessons Learned

Identity is increasingly becoming the core security perimeter in modern architectures.
